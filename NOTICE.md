# Attribution

Tier and effort rubrics, confidence/risk/ceiling rules, follow-up recognition, skill questions/gates/none policy, batching/shortlist/rerank rules, context minimization and platform markers are adapted from [Jev Pilot 0.12.1](https://github.com/Akramovic1/jev-pilot/tree/5d27135b34edf81b40c0bf1df01ae401f6b72ea7), commit `5d27135b34edf81b40c0bf1df01ae401f6b72ea7`, by Ahmed Akram, with portions by Daniel (San) Ávila. The upstream MIT notice is preserved in `LICENSE`.

This port targets official Pi, not Pi-Bolt. It implements effort selection, optional main-model tier routing through official virtual models, and main-session skill matching through Pi resources and context projection. Pi's skill catalog remains intact; content injection uses Pi resource-directory conventions rather than Claude-specific file lookup or path substitutions. Claude family/substring ranking is replaced with exact configured physical identities; initial balanced is an approved host default adaptation. No upstream mid-turn escalation, worker engine, health probes, pet, or live controls are imported.
