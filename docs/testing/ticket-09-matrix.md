# Ticket 09 — decision ledger, report and correction attribution matrix

Baseline: integration `51dfe53`; pinned Jev Pilot 0.12.1 `5d27135b34edf81b40c0bf1df01ae401f6b72ea7`, `hooks/ledger.ts` and `hooks/jev-model-router.ts` (entry shape, `LEDGER_SIZE=500`, `markCorrected`, `summarize`, report/reset). This matrix precedes the tests. Seams: pure ledger module, and the official Pi 1.4.0 RPC CLI with the packed extension, a local System One fixture and a local model fixture. Tuning proposals/apply/reset belong to ticket 10 and are not implemented here.

Storage: `<Pi agent dir>/jev-pilot/ledger.json` (`{ version: 1, entries }`), the Pi counterpart of upstream's plugin-store key `ledger`. Turn identity is `<session id>:<user message entry id>` of the turn's last user message. Correction attribution looks up the latest user message on the _current_ branch, so an abandoned branch, a new session or a turn that was never recorded is never marked.
