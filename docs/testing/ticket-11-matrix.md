## Scope observations (AC-27)

- `src/worker-adapter.ts` maps the agent names `jev-pilot:codex-review` and `jev-pilot:opencode-review` to the configured fast tier when a launch names them (ported from the upstream specialized branch; covered by `worker-adapter.test.ts`). The package registers no such agent, offers no mode for them and starts no external CLI; the mapping can only affect an agent a user or another package defines under that reserved name. It is documented in the README, not removed, because ticket 06/08 accepted it. Whether the reserved names should be dropped entirely is a scope decision for the parent.
- The tarball includes `docs/testing/pi-auto-visibility-evidence` terminal captures (`.raw`) from earlier tickets. They are test output, not datasets.

## Not verified (limits, not claims)

- Live-provider or hosted System One behavior, latency and classification quality. An optional smoke needs the user's credentials and an explicit cost boundary and was not run.
- Official Pi versions other than 1.4.0; Pi-Bolt; terminal rendering beyond the PTY runs recorded in `pi-auto-visibility-validation.md` and `live-status-validation.md`.
- `pi install npm:…` / `git:…` of this package itself (no registry package, no remote). The consumer `bun add` of the tarball plus `pi install <dir>` is the verified route.
- Installation without network or Bun cache access: the pinned executor dependency is a GitHub source.
- Coexistence of a second extension that needs the single required-child-extension registration (documented limitation).
