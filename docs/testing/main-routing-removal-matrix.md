## Verification boundaries

Run focused controls first, lint/format/typecheck separately with actual exits. Actual official Pi 1.4 CLI uses local deterministic HTTP fixtures, no hosted inference or personal settings changes. Record commands, source SHA and packed-artifact digest separately from runtime observations. Independent review and full regression remain required before install/push. No claim that retired virtual-route ACs pass under their old meaning.

Obsolete `jevPilot.mainRoutingEnabled` is ignored, as an unknown key, not validated or consumed. Remove it from settings; it cannot register a router or change selection. Legacy routing environment switches/mappings remain ignored. Worker tiers are JSON-only; unrelated env/auth configuration remains unchanged.
