## Verification levels

- `bun test tests/effort-policy.test.ts`: offline independent policy examples; **not E2E**.
- `bun test tests/pi-cli.test.ts`: actual stable Pi CLI subprocess, isolated temporary agent directory, installed local package, deterministic local HTTP System One and OpenAI-compatible model fixtures. RPC sends actual prompt/abort/session commands; provider request capture verifies dispatch. No paid APIs or user/global settings.
- `bun run typecheck`: exact published stable Pi 1.4.0 declarations (1.3.0 verification is historical).
- Live hosted Jev and real paid model credentials are intentionally not used. Local fixtures prove the host path, not model quality or hosted-service availability.
